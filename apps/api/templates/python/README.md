# My Python project

A friendly first Python program. It asks your name and a number, then answers you.

- `main.py`: the program. Start here.
- `requirements.txt`: the list of extra packages your program needs (empty for now).

## How to run it

1. Click **Open IDE** on the project page.
2. Open a terminal: menu **Terminal → New Terminal**.
3. Type this and press Enter:

   ```
   python3 main.py
   ```

4. Answer the questions in the terminal.

This program runs in the terminal, so there is nothing to Preview in a browser.

## Adding packages (optional)

If you need a package, make a private space for packages first (only once):

```
python3 -m venv .venv
source .venv/bin/activate
```

Then add the package name to `requirements.txt` and run `pip install -r requirements.txt`.
The `.venv` folder is only yours; it is never sent with your work.

## How to send your work

Your files live in **your copy** (your own space to work in). When you are happy with a change:

1. Click **Submit work** (send your changes for review).
2. Tick the files you changed, write a short title, and send it.
3. A teammate reviews it. When a leader merges it, it is added to **main** (the team's shared version).
