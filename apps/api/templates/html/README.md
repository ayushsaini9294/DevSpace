# My website

A simple website made with HTML, CSS and JavaScript.

- `index.html`: the page (what it says)
- `style.css`: how it looks (colours, sizes)
- `script.js`: what it does (the button)
- `server.js`: a tiny server that shows the page in Preview (you don't need to change it)

## How to run it

1. Click **Open IDE** on the project page.
2. Open a terminal: menu **Terminal → New Terminal**.
3. Type this and press Enter:

   ```
   npm start
   ```

   You will see "Your website is running on port 8080".

## How to see it

Click **Preview** in DevSpace (port **8080**). Your page opens in a new tab.
After you change a file and save it, reload that tab to see the change.

Tip: link your files without a `/` at the start (`style.css`, not `/style.css`), so they load in Preview.

To stop the server, click in the terminal and press Ctrl+C.

## How to send your work

Your files live in **your copy** (your own space to work in). When you are happy with a change:

1. Click **Submit work** (send your changes for review).
2. Tick the files you changed, write a short title, and send it.
3. A teammate reviews it. When a leader merges it, it is added to **main** (the team's shared version).
