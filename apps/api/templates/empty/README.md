# My project

Welcome! This project is empty, so you can start from nothing.

## How to start

1. Click **Open IDE** on the project page. The IDE is where you write code.
2. Make a new file in the file list on the left (for example `notes.md` or `index.html`).
3. Write something and save it (Ctrl+S, or Cmd+S on a Mac).

## How to see your app

If you build a web app, start it in the IDE terminal (menu **Terminal → New Terminal**).
Make it listen on `0.0.0.0` and a port like `8080`, then click **Preview** and pick that port.
Port 3000 is used by the IDE itself, so pick another one.

## How to send your work

Your files live in **your copy** (your own space to work in). When you are happy with a change:

1. Click **Submit work** (send your changes for review).
2. Tick the files you changed, write a short title, and send it.
3. A teammate reviews it. When a leader merges it, it is added to **main** (the team's shared version).
