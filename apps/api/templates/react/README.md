# My React app

A web app made with React and Vite. The page updates by itself when you save a file.

- `src/App.jsx`: the main part of the page. Start here.
- `src/App.css`: how it looks.
- `src/main.jsx`: starts the app (you don't need to change it).
- `vite.config.js`: settings for Vite, the tool that runs the app (keep it as it is).

## How to run it

1. Click **Open IDE** on the project page.
2. Open a terminal: menu **Terminal → New Terminal**.
3. Start the app:

   ```
   npm run dev
   ```

   The first time, it installs the packages it needs before starting, which takes about a
   minute. After that it starts in a few seconds.

## How to see it

Click **Preview** in DevSpace (port **5173**). Your app opens in a new tab.
Change `src/App.jsx`, save, and watch the tab update.

To stop the app, click in the terminal and press Ctrl+C.

Tip: put pictures in `src/` and `import` them, instead of using links that start with `/`,
so they load in Preview.

## How to send your work

Your files live in **your copy** (your own space to work in). When you are happy with a change:

1. Click **Submit work** (send your changes for review).
2. Tick the files you changed, write a short title, and send it.
3. A teammate reviews it. When a leader merges it, it is added to **main** (the team's shared version).
